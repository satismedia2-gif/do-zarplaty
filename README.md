# ДО ЗАРПЛАТЫ

Событийный симулятор российского быта: 100 дней между авансом и зарплатой.
Один день — одна карточка и один выбор. Решения возвращаются последствиями
через несколько дней: отложил ремонт машины — через три дня она встанет,
взял ночную подработку — наутро будешь кивать на планёрке.

Работает как обычный статический сайт (чистый HTML/CSS/JS, без сборки и
зависимостей) и как VK Mini App.

---

## Как запустить

**Локально:** открыть `index.html` двойным щелчком. Всё.

**Через сервер (если нужен порт):** `npx serve .` или `python -m http.server 8080`.

**ВКонтакте:** загрузить папку на https-хостинг, создать Mini App, указать URL.
`js/vk.js` сам поднимет VK Bridge, вызовет `VKWebAppInit`, покрасит шапку и
включит облачный сейв.

## Структура

```
index.html            три экрана: старт, игра, финал
style.css             тёмная тема, лэйаут 360–430 px, анимации
js/storage.js         localStorage: сейв, мета, миграции
js/events.js          схема, реестр (Events.add), условия, розыгрыш + базовые события и цепочки
js/events-pack-1.js   контент: работа, деньги, кредиты, подработки (50 событий)
js/events-pack-2.js   контент: семья, дети, соседи, ремонт, дача (35 событий)
js/events-pack-3.js   контент: магазин, машина, здоровье, отпуск (35 событий)
js/sound.js           6 звуков на WebAudio, без аудиофайлов
js/game.js            вся логика: цикл дня, эффекты, цепочки, достижения, финалы, счёт
js/ui.js              весь DOM
js/vk.js              VK Bridge (только внутри iframe)
tools/simulate.js     прогон тысяч партий в Node для баланса
```

Всего **157 событий**. Контент-паки подключены в `index.html` и докладывают
события через `Events.add([...])`; порядок подключения: `events.js` → паки →
`game.js` → `ui.js`.

Правило разделения: `game.js` и `events.js` не знают про DOM, `ui.js` не меняет
состояние. Поэтому логику можно прогонять в Node без браузера.

## Механики

**Основные характеристики:** 💰 деньги, ❤️ здоровье, ⚡ силы, 🙂 настроение, 🤝 отношения.
**Скрытые характеристики** (кнопка 📊 в игре): 👨‍👩‍👧 семья, 💼 репутация на работе,
🥱 усталость (режет восстановление сил ночью), 🍀 удача (сдвигает шансы риск-бросков),
🎲 склонность к риску, 🎓 опыт плюс счётчики: подработки, поломки, долги, вечеринки,
добрые дела, экономия.

**Цепочки.** У варианта можно указать `next: { id: 'событие', in: 3 }` — через три дня
это событие придёт как «последствие» (в карточке появляется плашка). События-последствия
помечаются `queued: true` и в обычный розыгрыш не попадают. Цепочек в игре больше 20,
самые длинные — 4–5 шагов (карьера, машина, ремонт, дача).

**Достижения (18).** От «Пятница пережита» до «Экономист года». Дают очки в рейтинге,
всплывают плашкой и показываются списком на экране финала.

**Финалы (18).** От «Рантье из панельки» до «Долговой ямы». Выбирается первый
подходящий по приоритету.

**Рейтинг** считается не только по деньгам:
`дни ×90 + деньги + здоровье + настроение + отношения + семья + работа + состояние машины + опыт + достижения + подработки − долг − усталость`.

**Поражения:** здоровье 0, настроение 0, ноль сил два дня подряд, минус 50 000 ₽.

**Календарь:** 1-е — квартплата, 5-е — платёж по кредиту, 12-е — кредит за машину,
15-е — аванс, 30-е — зарплата.

Прогресс сохраняется после каждого действия: можно закрыть вкладку и вернуться.

## Как добавить событие

```js
{
  id: 'my_event', icon: '🎈', rarity: 'common', weight: 8, minDay: 5, cooldown: 10,
  chain: 'my_chain',                 // опц.
  title: 'Короткий заголовок',
  text: 'Одна-две строки описания.',
  require: { car: true, money: 5000 },     // опц.
  choices: [
    {
      id: 'a', label: 'Что сделать', icon: '✅', hint: '−1 000 ₽',
      cost: { money: 1000, category: 'fun' },
      effects: { mood: +8, energy: -5, family: +3 },
      risk: [{ chance: 0.2, text: 'Неприятность', effects: { money: -2000 } }],
      next: { id: 'my_event_part2', in: 2 },
      requires: { money: 1000 },
      result: 'Что произошло.'
    },
    { id: 'b', label: 'Ничего не делать', icon: '🛋', hint: 'бесплатно',
      effects: { mood: -2 }, result: 'Ничего и не произошло.' }
  ]
}
```

Эффекты: `money, health, energy, mood, social, family, work, fatigue, luck, risk,
exp, carCondition, carGone, creditAdd, creditPay, flag, unflag, category,
gigs, breakdowns, debts, parties, charity, repairs, savings`.
Условия (`require` и `requires`): `car, money, moneyBelow, credit, flag, flagNot,
healthAbove/Below, energyAbove/Below, moodAbove/Below, socialAbove/Below,
familyAbove/Below, workAbove/Below, fatigueAbove/Below, luckAbove/Below, expAbove,
riskAbove, carCondAbove, carCondBelow, counterAbove: { gigs: 3 }`.

**Правило:** минимум один вариант без `cost` и без `requires`, иначе при нуле денег
все кнопки станут серыми. На этот случай есть страховка «Просто пережить этот день».

## Проверка и баланс

Проще всего — двойной щелчок по **`run-checks.cmd`**: он сам находит Node
(PATH → комплект DSH → Program Files), проверяет синтаксис всех десяти
скриптов и запускает симуляцию на 2000 партий.

Вручную:

```
node --check js/game.js
node --check js/events.js
node --check js/ui.js
node --check js/storage.js
node tools/simulate.js 2000
```

Симулятор прогоняет три стратегии (почти оптимальная / полуоптимальная 50-50 /
наугад), печатает выживаемость, причины финала, финалы, структуру трат,
среднее число достижений, износ и усталость в конце, а также список событий,
которые ни разу не выпали.

Дальше он **сам подбирает износ**: пять вариантов `strainEnergyEvery` /
`strainHealthEvery` / `strainRest` / `baseHealthDrain`, замер на каждой
конфигурации и вывод готовых строк для `BALANCE`.

Ориентиры выживаемости:

| Стратегия | Цель |
|---|---|
| почти оптимальная | 20–35% |
| полуоптимальная (50/50) | **12–20%** |
| наугад | ниже 8% |

Если полуоптимальная ниже 8% — ослабь износ (`strainEnergyEvery` 3,
`strainHealthEvery` 4, `strainRest` 3). Если выше 30% — подними
`baseMoodDrain` / `moodLoss` или опусти `strainRest` до 1.

### Проверенный баланс (2000 партий, 157 событий, случайные цели и профессии)

| Стратегия | Выживаемость | Средняя длительность | Деньги в конце |
|---|---|---|---|
| почти оптимальная | 13.4% | 40 дней | 12 200 ₽ |
| полуоптимальная (50/50) | **19.3%** | 46 дней | 20 200 ₽ |
| наугад | 23.4% | 49 дней | 19 900 ₽ |

По профессиям (полуоптимальный бот): офисный клерк 13%, студент 20%, курьер 24%.
Главная причина провала — настроение (69–78% финалов), дальше долги и здоровье.
Мечта выполняется в 11–13% партий: это осознанно сложная цель с бонусом к рейтингу.

**Известное ограничение:** боты симулятора — примитивные эвристики, поэтому
разрыв между «умной» и «случайной» стратегией получился слабым (13% против 23%).
Это ограничение бота, а не обязательно игры: скрипт `valueOf` в
`tools/simulate.js` — единственное место, где стоит улучшать «интеллект» замеров.

## Что нового в версии 2.0

**Цели и мечты.** На старте выбирается одна из 5 целей: дожить до отпуска,
купить дачу (100 000 ₽), закрыть все кредиты к 80-му дню, накопить 200 000 ₽,
сохранить семью. За выполненную мечту — бонус к рейтингу, прогресс виден чипом в HUD.

**Профессии.** Три архетипа с разной экономикой: офисный клерк (ровный оклад
78 000 ₽/мес), курьер-фрилансер (доход зависит от сил: устал — заработал меньше),
студент-ипэшник (быт дешевле, но импульсивные траты в 1,45 раза чаще).

**Сезоны и микро-кризисы.** Партия длится 100 дней ≈ 3,5 месяца: зима дороже по
квартплате и бензину, лето дешевле по еде. Раз в 12 дней приходит глобальное
событие на 7–30 дней: подорожание бензина, тарифы ЖКХ, сезон распродаж, индексация
зарплаты или микро-кризис с урезанием премий.

**Перки и очки опыта.** За партию начисляются очки (рейтинг + бонус за выживание
и мечту). Пять постоянных перков покупаются между партиями: Кэшбэк (−45% к
случайным тратам), Крепкий сон, Связи (−10% ко всем тратам в событиях),
Второе дыхание (+1 200 ₽/день), Родился в рубашке (+12 удачи).

**Ежедневный забег.** Кнопка «🌍 Ежедневный забег» запускает партию с зерном,
посчитанным из даты: у всех игроков в этот день одинаковые события и одинаковые
броски риска — можно честно сравнивать результаты.

**Журнал расходов (📒).** За последние 7 дней: полосы по категориям и список
операций «день → что → сумма». Видно, что съедает деньги: быт, импульсы или кредит.

**Состояние игрока.** Аватар в HUD меняется по показателям (😄 → 🙂 → 😐 → 🥴 →
😩 → 🤒 → 😰), при низком настроении или износе экран «тускнеет».

**Темы.** Три оформления (тёмная / светлая / ретро-90е) переключаются кнопкой
🎨 и хранятся в мете. Тема меняет только вид, не баланс.

**PWA и офлайн.** `manifest.json`, `icon.svg` и `service-worker.js`: игра
устанавливается на телефон и открывается без интернета. На `file://` service
worker недоступен и молча пропускается.

**Валидатор контента.** `node tools/validate.js` проверяет 157 событий:
уникальность id, обязательные поля, известные ключи эффектов и условий, наличие
хотя бы одного бесплатного варианта, существование всех ссылок цепочек,
длину текстов под мобильный экран. Уже поймал одну реальную ошибку.

**Схема контента — одна на движок и проверку.** `Events.schema` в `js/events.js`
описывает допустимые ключи эффектов, условий, категорий и редкостей;
`tools/validate.js` читает её оттуда же, поэтому списки не разъедутся.
Каждое событие из пака проходит `Events.validate` при регистрации: битое
пропускается с предупреждением в консоли, а не роняет игру.
Шаблон для новых карточек — `content/events-template.js` (3 примера: простое
событие, цепочка из двух шагов, риск с двумя взаимоисключающими исходами).

**«Занять у друга» (ВК).** Работает без backend: VK Storage в мини-аппе общий
для всего приложения, поэтому просьба и ответ лежат в ключе `dz_ask_<id>`.
Просящий отправляет другу ссылку с якорем `#help=<id>&sum=<сумма>`; друг
открывает игру, видит просьбу, жмёт «Дать» — деньги приходят просящему в
текущую партию (или копятся в мете до начала следующей). По кнопке в меню.

**Карточка результата.** Кнопка «🖼 Карточка результата» рисует на canvas
вертикальную карточку 1080×1920 (финал, дни, деньги, мечта, рейтинг,
профессия, достижения) и отдаёт её в системное «Поделиться» файлом, а если
Web Share с файлами недоступен — скачивает PNG. В ВК при заданном
`__VK_STORY_BG` сначала пробуются нативные Stories.

Исправлены реальные наложения и обрезки:

## Публикация в ВКонтакте

Игра — статический сайт: backend не нужен, база не нужна. Порядок:

**1. Хостинг с HTTPS.** Подойдёт статический хостинг ВК (в кабинете приложения),
GitHub Pages, Netlify или Cloudflare Pages. Заливается всё содержимое папки:
`index.html`, `style.css`, `icon*.*`, `manifest.json`, `service-worker.js`,
`js/`. Папку `content/` можно не заливать — это шаблон для новых событий.

**2. Создать мини-приложение** в кабинете `vk.com/editapp?act=create`, указать URL
хостинга. Тип — игра/мини-приложение, категория «Игры», возрастной рейтинг 12+.

**3. Что заполнить в настройках приложения:**

| Поле | Чем заполнить |
|---|---|
| Иконка 512×512 | `icon-512.png` (лежит в проекте) |
| Название | «До зарплаты» |
| Описание | из `manifest.json` → `description` |
| Обложка и скриншоты | 1080×1920, минимум 3 |
| Политика конфиденциальности | обязательна ссылка; игра не собирает персональные данные, только id для облачного сейва |
| Лидерборды | 4 таблицы, их ID вписать в `VK.LEADERBOARDS` в `js/vk.js` |

**4. app_id подставляется сам.** `js/vk.js` читает `vk_app_id` и `vk_user_id`
из подписанных launch-параметров ВК, поэтому ссылки на приложение и таблицы
лидеров работают сразу, без ручной правки кода.

**5. Облачный сейв персонализирован.** Ключи `dz_save_<id игрока>` и
`dz_daily_<дата>_<id>`: в VK Storage ключи общие для всего приложения, поэтому
без префикса игроки перезаписывали бы партии друг друга. Журнал расходов в
облако не уходит — он не влезает в лимит 4096 байт на ключ.

**6. Перед каждой заливкой:** поднять `CACHE_VERSION` в `service-worker.js`
(иначе игроки останутся на старой версии из кэша) и прогнать `run-checks.cmd`.

### Риск на модерации

В контенте есть лотерея, крипта и микрозаймы. Правила ВК ограничивают
пропаганду азартных игр и финансовых рисков. У нас всё подано сатирически
(крипта теряет деньги в 65% случаев, микрозайм ведёт к коллекторам), но
модератор может придраться к формулировке «выигрыш +50 000 ₽». Варианты:
дисклеймер «игра — сатира, не финансовый совет» на стартовом экране или
срезать крупные выигрыши.

## Как выложить на GitHub Pages

Все пути в проекте относительные, поэтому игра работает и в корне домена, и в
подпапке вида `https://логин.github.io/имя-репозитория/`. GitHub Pages отдаёт
сайт по HTTPS — это обязательное условие и для service worker (офлайн), и для
запуска внутри ВКонтакте.

### Вариант «мышкой», без Git

1. На github.com создай репозиторий: **New repository** → имя `do-zarplaty` →
   **Public** (на бесплатном плане Pages работает только для публичных) → Create.
2. На странице репозитория: **Add file → Upload files**. Перетащи в окно:
   `index.html`, `style.css`, `manifest.json`, `service-worker.js`, `.nojekyll`,
   `icon.svg`, `icon-192.png`, `icon-512.png`, папку `js` целиком и, по желанию,
   `README.md`. **Важно:** всё это должно оказаться в корне репозитория, а не
   внутри вложенной папки, иначе адрес станет длиннее на один уровень.
3. Внизу страницы **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**,
   папка **/ (root)** → **Save**.
5. Через 1–2 минуты игра откроется по адресу
   `https://<логин>.github.io/do-zarplaty/`.

### Вариант через Git

```
cd C:\Users\я\Desktop\ор\do-zarplaty
git init
git add -A
git commit -m "До зарплаты: первая публикация"
git branch -M main
git remote add origin https://github.com/<логин>/do-zarplaty.git
git push -u origin main
```

Либо просто запусти `deploy-github.cmd` и вставь адрес репозитория — скрипт сам
сделает init, commit и push. Шаг с включением Pages в настройках всё равно
нужен один раз.

### После каждой правки игры

1. Подними `CACHE_VERSION` в `service-worker.js` (`v2` → `v3`) — иначе
   вернувшиеся игроки получат старую версию из кэша.
2. Залей изменения (`git add -A && git commit -m "..." && git push`, либо снова
   Upload files).
3. Проверь: в браузере DevTools → **Application → Service Workers → Update**,
   затем обычная перезагрузка страницы.

### Что заливать не нужно

`tools/` (валидатор и симулятор — это Node-скрипты для разработки),
`run-checks.cmd`, `deploy-github.cmd`, `content/` (шаблон для новых событий).
Ничего не сломается, если их залить, но браузер их просто не использует.

### Если репозиторий приватный

На бесплатном плане Pages для приватных репозиториев недоступен. Тогда либо
делай публичный репозиторий, либо выкладывай ту же папку на Netlify или
Cloudflare Pages (там приватность исходников не мешает).

## Звук

`js/sound.js` синтезирует эффекты на месте: `tap, coin, notify, rare, win, lose`.
Аудиофайлов нет. Чтобы подключить настоящие звуки — заполнить таблицу `FILES`:
